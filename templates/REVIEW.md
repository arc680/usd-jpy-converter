# レビュー観点

実装者とは別のエージェントが、PR に対して以下を確認する。

- [ ] 仕様（対応 Issue）との適合: 範囲外の変更が混ざっていないか、対象外を侵していないか
- [ ] 受け入れ条件: 各条件をどう検証したかが PR に書かれているか
- [ ] 正確さ: 計算・データ形式・境界条件（空、最大、重複）
- [ ] 表示・文言: プロジェクト側の表記ルールと合っているか
- [ ] 秘密情報: 認証情報や個人情報が含まれていないか

指摘は「直す」か「仕様側の問題として Issue に戻す」かを分けて書く。レビューのみの参加では Co-authored-by 署名は付けない（署名は実装分のみ）。
