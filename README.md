# ドル円変換（買い物用）

アメリカでの買い物向けの USD/JPY 換算ツール。単一ファイル `index.html` の静的スペース「ドル円変換」（slug: doruyuan-bian-huan）として設置している。

- 店頭の税別価格（USD）から円へ換算。［シンプル］は基準レートのみ、［実払い］は現地税率＋カード海外事務手数料を上乗せし、内訳も表示
- 税率は主要都市プリセット（初期: ホノルル 4.712%）＋手入力。手数料はプリセット（初期: 3.63%）＋手入力
- JPY → USD の逆換算（予算から買える棚価格を逆引き）対応
- レートは ExchangeRate-API／Frankfurter（ECB）／Currency-API の3元へ同時問い合わせし、最初に届いた妥当な値を採用（各8秒タイムアウト、全部失敗時は1回だけ自動再試行）。手入力での上書きも可

仕様の正本は `SPEC.md`、プロジェクト情報は `PROJECT.md`、進め方のルールは `AGENTS.md`（テンプレート共通）。計算関数は Node.js で受け入れ例と照合して検収する。
